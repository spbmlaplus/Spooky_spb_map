# Новая локация: особняк княгини Кугушевой

Добавлена по уточнённому выбору пользователя: дом с присланной фотографии. Боковая аллея, 1, Каменный остров. Координаты 59.9782694, 30.2854694 по Wikimedia Commons (59°58′41.77″N, 30°17′07.69″E).

Первоначально указанные 59.977497, 30.279637 относятся к другому объекту — особняку Мельцера. Эти объекты не объединялись.

Адрес: https://mostotrest-spb.krti.gov.spb.ru/football/route/istoricheskie-dachi
Архитектор, материалы, художественная школа: https://p118.spb.ru/progulka-vokrug-stancii-metro-chernaya-rechka/
Координаты: https://commons.wikimedia.org/wiki/Category:Kugusheva_Mansion
